# 岗位筛选偏好

这个文件用于覆盖 `daily-job-picks` skill 的默认公共精选倾向。它不是代码配置，直接按群友投票和人工判断维护即可。

## 本期总数

建议筛选 8 个岗位。质量不足时可以少于 8 个，不要为了凑数放入弱匹配、坏链、疑似不可投或不适合中国大陆申请人的岗位。

## 岗位方向优先级

- 运营，合规，KYC：17
- 客服：15
- 教育：13
- 售后支持 / 客户成功：12
- 其他：9
- HR：8
- 销售 / BD：8
- 产品 / 产品经理：7
- 数据处理 / 数据分析：7
- 软件开发 / 技术开发：7
- web3：6
- 软件测试：6
- 采购，供应链：6
- 设计，作图：3
- 医药：3
- 内容 / 新媒体：2
- AI Trainer / 数据标注：2
- 质量工程：2

## 工作方式优先级

- 都可以 / 有工作就行：19
- 国内 / 中国远程：12
- 海外 / APAC / 全球远程：7
- 外企，可以不远程：6

## 英文要求倾向

- 优先照顾低英文门槛和能读写英文的岗位。
- 可以保留少量高英文要求岗位，但不要让它们占多数。

## 经验阶段倾向

- 优先覆盖入门、1-3 年、3-5 年。
- 高级岗位可以出现，但不应成为公共精选主体。

## 申请门槛倾向

- 优先低门槛和中等门槛。
- 高门槛岗位只在公司质量、岗位匹配度、可投把握都较强时保留。

## 明确排除

- 不要默认收录海外 Mandarin AI Trainer、Simplified Chinese Evaluator、Chinese Data Annotator、数据标注、AI 评分类岗位，除非页面明确支持中国大陆申请或中国大陆工作地点。
- 避开高风险 crypto、博彩、成人行业、刷单、纯佣金高薪销售、付费入职、培训费、押金、隐藏公司身份的岗位。
- 不要使用平台首页、搜索页、职位列表页、过期页、404 或需要登录才能看到岗位详情的链接。

## 当天配比建议

如果当天目标是 8 个岗位，优先尝试：

- 运营 / 合规 / KYC / 客服 / 客户成功：3-4 个
- 教育 / 内容 / 本地化 / 低英文门槛岗位：1-2 个
- HR / 销售 / 供应链 / 项目支持 / 业务分析：1-2 个
- 产品 / 数据 / QA / 技术 / 技术支持：1-2 个

如果某一类当天找不到可靠岗位，可以用相邻高需求类别替代，并在内部筛选时优先保证中国大陆可投和链接可用。
