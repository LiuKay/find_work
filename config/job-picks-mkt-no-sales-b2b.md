# MKT 定向筛选标准：去销售 / 去 B2B

用途：当用户说“筛 mkt 岗位”“按 mkt 标准”“按照上面的 mkt 要求”时，优先使用本文件作为定向筛选标准。

## 核心目标

- 筛选外企或小而美外企的市场类岗位，优先 B2C、消费品、餐饮饮料、生活方式、零售、电商、品牌、内容、社媒、PR、活动、CRM、会员运营、消费者增长。
- 优先上海、杭州；其次中国大陆本地岗位；再次才考虑明确支持中国大陆申请的 APAC / Asia 远程岗位。
- 经验优先 3-5 年和 5 年以上；高级岗位可保留，但不要让总监级岗位占多数。
- 默认目标数量 6-8 个。质量不足时少于 6 个也可以，不要为了凑数加入销售、B2B 或弱匹配岗位。

## 必须排除

- 销售 / BD / 商务拓展 / Account / Key Account / Sales Engineer / Sales Enablement / Partner Sales / Channel Sales。
- 以企业客户获客、SaaS lead generation、B2B field marketing、ABM、enterprise demand generation 为主的岗位。
- 工业软件、开发者工具、云服务、供应链 SaaS、支付 SaaS、MarTech SaaS 等明显 B2B 岗位，除非职责主要是 B2C 内容、品牌传播或消费者活动。
- 主要目标客户是企业、开发者、渠道商、代理商、分销商、经销商、医院、药企、制造企业的市场岗位。
- 纯销售指标、客户开发、pipeline、revenue quota、commission、hunter、cold outreach、sales target 为核心的岗位。
- 高风险 crypto、博彩、成人行业、刷单、灰产、纯佣金高薪销售、付费入职、培训费或押金岗位。

## 优先保留

- Brand Marketing / Brand Manager / Assistant Brand Manager / Consumer Marketing。
- Trade Marketing / Shopper Marketing / Retail Marketing，但必须偏消费者、门店、陈列、促销、campaign，不要偏渠道销售。
- Digital Marketing / Performance Marketing / Growth Marketing，但必须面向消费者、电商、DTC、App、会员或内容增长，不要 B2B 获客。
- Social Media / Content Marketing / Copywriting / Creative / Community / Influencer / KOL / Creator Marketing。
- PR / Communications / Product Communications，但优先消费品、生活方式、餐饮饮料、零售、文娱、旅游、酒店、运动、服饰、美妆。
- E-commerce Marketing / Marketplace Marketing / CRM / Loyalty / Membership / Campaign Operations。
- Event Marketing / Experiential Marketing / Brand Partnership，仅保留品牌联名、消费者活动、内容合作类；排除商务拓展和销售型 partnership。
- Product Marketing 仅在面向消费者产品、消费电子、生活方式产品或电商产品时保留；排除 B2B SaaS 产品营销。

## 行业优先级

1. 餐饮、饮料、咖啡、茶饮、食品、FMCG。
2. 服饰、鞋包、运动、户外、美妆、个护、家居、生活方式。
3. 酒店、旅游、娱乐、游戏、文创、IP 授权、零售、电商。
4. 消费电子、智能硬件、汽车后市场等消费者可感知品类。
5. 小而美外企的 B2C 内容、品牌、社媒、活动、PR 岗位。

## 申请门槛和可投说明

- `申请门槛` 必须写成 `低 / 中 / 高 + 一句简短说明`。
- `中国可投把握` 必须写成 `高 / 中 / 待确认 + 一句简短说明`。
- 如果工作地点、签约主体或中国大陆远程雇佣不明确，写 `中国可投待确认`，并在注意事项里提醒投递前确认合同/税务/雇佣形式。

## 输出偏好

- 文件名建议：`job-picks/YYYY-MM-DD-mkt-no-sales-b2b.md`。
- 标题建议：`# YYYY-MM-DD MKT / 去销售去 B2B 岗位专选`。
- 数量写实际保留数量。
- 注意事项只写岗位本身的适配点、风险和投递前确认项；不要写“符合去销售/去 B2B 标准”“符合新标准”“不是 B2B lead generation”这类内部筛选说明，也不要把销售或 B2B 岗位包装成 MKT。
